# the idea and the design
So, the idea is something that an NFC sticker can be attached to—which means it has to be circular!

At first, I thought about making a vinyl record player, complete with a vinyl disc, 
but I wasn't sure how to make it look good. Besides, I’d already suggested that idea to a friend, so I decided to come up with something else. 
I was searching for inspiration, but nothing came to mind until I remembered my profile 
name: "Coding Shark." 
I decided to create something that’s very "shark-like," but cute and not too aggressive. 
So, I ended up designing a circular shark, incorporating a motif that looks like an X-ray of a fish skeleton.
